# data-quality-agent
An intelligent assistant that can inspect a CSV dataset, identify data quality issues and prepare a report using Python tools.

What it will do:
- Understand natural-language requests.
- Inspect a dataset.
- Detect missing values.
- Find duplicate records.
- Examine sample rows.
- Analyze results and generate a report.


Technology stack:
Python
Ollama
Llama 3.2
Tool Calling
CSV
